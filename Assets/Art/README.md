# Artwork sources

`apollo17-earth.jpg` is a resized copy of NASA's Apollo 17 photograph AS17-148-22727, taken on December 7, 1972. Credit: NASA. The original is available from [The Blue Marble: The View From Apollo 17](https://www.nasa.gov/image-article/blue-marble-view-from-apollo-17/). It is included as photographic input for a rendering example, subject to [NASA's image and media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). The example and its modified QR output do not imply NASA endorsement.

The other expressive-art sample illustrations are drawn by `QrArtIllustrations.cs` in the examples project and use the repository's license. No image-generation service is used.
