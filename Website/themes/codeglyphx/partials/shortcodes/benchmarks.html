Supplemental PDF417 images

A separate check uses all 38 PNG images with text oracles from the same three upstream PDF417 folders outside the 18 frozen cases. The selection was fixed before the first supplemental outcomes. A failure there informed the final correction and a permanent regression test, so this is supplemental regression evidence rather than an unseen holdout. It does not replace the 267-positive-image ranking or establish performance on an independent dataset.
