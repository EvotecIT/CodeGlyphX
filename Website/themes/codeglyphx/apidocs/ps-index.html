PowerShell

ImagePlayground commands

The CodeGlyphX commands in the ImagePlayground module, generated from its help. Each tile is a file one of them wrote in the PowerShell examples.

  • New-ImageQRCodeQR codes with colours, shapes and logos.
  • New-ImageBarCodeCode 128, EAN, Data Matrix, PDF417.
  • New-ImageQRCodeWiFiJoin a network by scanning.
  • New-ImageQRContactA contact card for phones.
  • New-ImageQRCodeOTPAuthenticator enrolment codes.
  • Get-ImageQRCodeRead a QR code back from an image.
