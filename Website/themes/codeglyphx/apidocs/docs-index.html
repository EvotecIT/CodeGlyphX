API reference

Every public type in the CodeGlyphX package, generated from its XML documentation and linked to the source on GitHub. Most work starts at one of these entry points; each tile is what it produces.

  • QREncode, style and save QR codes.
  • BarcodeLinear symbologies, Code 128 to postal.
  • DataMatrixCodeSquare and rectangular Data Matrix.
  • Pdf417CodePDF417 and MicroPDF417.
  • AztecCodeCompact and full-range Aztec.
  • QrPayloadsWi-Fi, contacts, OTP and payments.
  • SymbolScannerFind and decode codes in images.
