# Supplied-font fixtures

OfficeIMO Baseline Sans regular and italic are the unchanged Latin-subset fixtures from `EvotecIT/OfficeIMO`, `OfficeIMO.TestAssets/Fonts`. They derive from Carlito and use the renamed family supplied by that project. Copyright and the SIL Open Font License are retained in `OFL-Carlito.txt`.

These files qualify loading, case preservation, missing-glyph reporting, outline bounds and printing without relying on installed system fonts. They are embedded only in the test assembly and are not bundled label fonts.

## Original outline fixtures

`TestOutlines.ttf`, `TestOutlines.otf` and `TestOutlines.ttc` contain original, simple test
glyphs generated by `Build/Generate-PrintFontFixtures.py` using fontTools 4.67.0.
They are covered by the repository's Apache-2.0 license. Their purpose is to distinguish
quadratic and cubic curves, holes, overhang, GSUB ligatures, Arabic joining, supplementary
Unicode and collection faces with different metrics. They are not OCR designs or production fonts.
`test-font-metadata.json` records independent BoundsPen measurements and artifact hashes.
`TestOutlineBudget.ttf` is an original, acyclic graph of empty composite glyphs used to verify
the font reader's work limit independently of its emitted-point limit.

`TestOutlinesCff2.otf` is the CFF fixture converted to CFF2 by fontTools. The two compressed CFF2
metadata fixtures distinguish shared subroutine references from distinct indices that exceed
the cumulative parsing limit. `TestSubstitutionCoverage.ttf.gz` has repeated nonmatching coverage
ranges to exercise the shaping work limit. These bounded fixtures expand to at most 3 MiB;
the tests do not run the large-memory or long-running forms of the malformed inputs.

`TestMixedCffFirst.ttc` and `TestMixedTrueTypeFirst.ttc` combine the original CFF, CFF2 and
TrueType fixtures in different orders. `Build/Generate-PrintFontCollections.py` uses pinned
input hashes and fontTools 4.67.0; `test-collection-metadata.json` records the face order,
distinct nominal and ligature advances, and collection hashes. These qualify explicit and
automatic face selection, shaping cache isolation and outline exports.

`Build/Generate-PrintFontLayoutFixtures.py` creates the original `TestKerning*`,
`TestLayoutSubstitution`, `TestTrackingAndSelectors` and `TestVariable*` fonts. They qualify
pair/class/extension kerning, legacy precedence, coverage-based substitutions, text clusters,
variation selectors, normal tracking, and variable outlines/metrics with and without HVAR.
`test-layout-metadata.json` records fontTools instance advances, BoundsPen measurements and hashes.

`Build/Generate-PrintCffPrograms.py` authors the original `TestCffPrograms.otf` operator programs.
`test-cff-program-metadata.json` records independent BoundsPen bounds for curves, hints and
subroutines; the arithmetic programs draw an explicitly authored 540 by 700 design-unit box.
Both tools use fontTools 4.67.0 and run only when a maintainer chooses to regenerate fixtures.

The same CFF generator creates original CID fonts with two local-subroutine dictionaries
and FDSelect formats 0, 3 and 4, a composed accent, and a variable CFF2 font. The CFF2
dictionary fixture continues drawing after both local and global subroutine calls,
which end implicitly in CFF2. An unterminated CFF1 variant verifies that CFF1 still
requires an explicit return. Their hashes and independent variable-instance bounds
are recorded in `test-cff-program-metadata.json`.

`BidiMirroring-17.0.0.txt` is the unchanged Unicode 17.0 mirroring data from
https://www.unicode.org/Public/17.0.0/ucd/BidiMirroring.txt (SHA-256
`a2f16fb873ab4fcdf3221cb1a8a85a134ddd6ed03603181823ff5206af3741ce`). It supplies independent
expected pairs for the generated mirroring table. Its Unicode copyright notice is retained;
the full license is also in `Licenses/Unicode-LICENSE.txt`.
